# Rating Service

Репутация пользователя и правила, которые из неё следуют: сколько книг он может держать
на руках (`maxBooks = stars / 3`), сколько звёзд снимается за просрочку и за изменившееся
состояние книги и сколько начисляется за аккуратный возврат. Рейтинг всегда остаётся в
диапазоне 1–100, новый пользователь заводится при первом обращении.

Сервис получает от Gateway факты о закрытом резерве и сам решает, нарушение это или нет.

Подробности — в [design.md](../design.md).

## Запуск

```bash
poetry install
poetry run uvicorn rating.main:app --port 8050
```

## Тесты

```bash
poetry run pytest
```
